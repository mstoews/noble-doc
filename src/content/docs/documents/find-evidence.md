Open **System → Documents**. The workspace is titled **Evidence** and places a journal list beside associated documents.

## Find supporting evidence

1. Review the date-range control at the top and select the period you need.
2. Search the journal list by description and select the intended journal.
3. Check the journal number, description, and item count in the evidence area.
4. Use **Open journal** to review the transaction. Where document cards exist, select a thumbnail to open the file in a new tab.

**All in period** shows the period's evidence. **Unassigned** helps find evidence not linked to a journal. A journal without attachments displays **No evidence here**; check the date range and Unassigned view before concluding the document is missing.

## Add or correct an assignment

The **Evidence** toolbar button opens **Transaction Evidence**, where **Browse for file** and drag-and-drop are available. After an upload completes, locate its evidence card and verify the assignment rather than assuming the selected journal received it.

To edit an existing card, select its description area. **Edit Evidence** provides **Assign to journal**, **Reference**, and **Description**. Review the values and choose **Save Evidence**. Reopen the journal's evidence view to confirm the document is attached to the intended transaction.

## Prepare for review

Use descriptions and references that connect the document to its transaction. Open the file to check readability and completeness. Continue to [Audit Trail](/documents/audit-trail/) for recorded actions, or [audit preparation](/guides/prepare_for_audit/) for the broader review.
